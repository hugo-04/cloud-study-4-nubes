# Azure · Policy · Catálogo NET-01…NET-12 (reglas de red de ModaLima → mecanismo de cumplimiento)

Este catálogo conecta las reglas del capítulo de red ([diagnóstico de conectividad](../../01-red/diagnostico-conectividad/README.md)) con **lo que las hace cumplir** en Azure. No todas las reglas se pueden imponer con Azure Policy: algunas se **verifican** (Resource Graph, diagnóstico) o se **garantizan por diseño** (IaC, RBAC).

Los identificadores GUID son los de las **políticas integradas** (verificados contra la documentación; *confirma que siguen vigentes antes de asignar*). El efecto se pasa como parámetro cuando la definición lo permite.

| Regla | Qué exige | ¿Cómo se impone? | Política integrada (nombre → ID) | Efecto recomendado |
|---|---|---|---|---|
| **NET-01** Negar por defecto entre subnets | NSG con denegación por defecto y reglas mínimas | Política **parcial** + revisión | *Subnets should be associated with a Network Security Group* → `e71308d3-144b-4262-b144-efdc3cc90517` · *All network ports should be restricted on network security groups associated to your virtual machine* → `9daedab3-fb2d-461e-b861-71790eead4f6` | `AuditIfNotExists` |
| **NET-02** Solo el punto de entrada tiene IP pública | Sin IP pública en interfaces de red de backends | **Impone** | *Network interfaces should not have public IPs* → `83a86a26-fd1f-447c-b59d-e51f44264114` | `Deny` (en `Corp`) |
| **NET-03** PaaS con Private Endpoint y acceso público desactivado | `publicNetworkAccess = Disabled` en cada servicio | **Impone** (una política por servicio) | Storage → *Storage accounts should disable public network access* `b2982f36-99f2-4db5-8eff-283140c09693` · Cosmos DB → *Azure Cosmos DB should disable public network access* `797b37f7-06b8-444c-b1ad-fc62867f335a` · Key Vault → *Azure Key Vault should disable public network access* `405c5871-3e91-4644-8a63-58e19d68ff5b` · SQL → *Public network access on Azure SQL Database should be disabled* `1b8ca024-1d5c-4dec-8995-b1a932b41780` · Event Hubs → *Event Hub Namespaces should disable public network access* `0602787f-9896-402a-a6e1-39ee63ee435e` · Service Bus → buscar *Service Bus Namespaces should disable public network access* en *Definiciones* | `Audit` → `Deny` |

## Qué política va en qué grupo de administración
| Grupo | Reglas | Por qué |
|---|---|---|
| **Raíz de ModaLima** | NET-12 (regiones permitidas, etiquetas), NET-05 (sin claves), NET-08 (flow logs, auditoría) | Aplican a **todo** |
| **Corp** (apps internas) | NET-02 (sin IP pública), NET-03 (PaaS sin acceso público), NET-06 | Solo red privada |
| **Online** (expuestas) | NET-03 con excepciones documentadas para el punto de entrada, NET-10 | Hay un punto de entrada público (Front Door/App Gateway) |
| **Sandbox** | Región, presupuesto, SKU permitidos; sin NET-03 estricta | Pruebas con límites de costo |

## Orden de despliegue (sin romper a nadie)
1. Asignar la iniciativa con **todos los efectos en `Audit`** (o `DoNotEnforce`).
2. Esperar un ciclo de 24 horas y exportar el cumplimiento por equipo.
3. Corregir lo existente (remediación o trabajo de cada equipo) y publicar el plan.
4. Cambiar a `Deny` **primero en Sandbox y Dev**, después en Prod.
5. Dejar `Audit` activo para lo que no se puede bloquear.
