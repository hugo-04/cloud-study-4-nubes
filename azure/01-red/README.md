| 2 | [NSG, Rutas y NAT](nsg-rutas-nat/README.md) | Guardias, señales y puerta de salida: reglas, prioridades, UDR, SNAT |
| 3 | [Private Endpoint y DNS](private-endpoint-dns/README.md) | Puerta interna a PaaS y la guía telefónica privada |
| 4 | [Peering y Hub-and-Spoke](peering-hub-spoke/README.md) | Puentes entre redes y el diseño central |
| 5 | [Comunicación privada y diagnóstico](diagnostico-conectividad/README.md) | RPDSI, escalera de diagnóstico, Network Watcher |

Cada carpeta trae: teoría, casos reales, uso desde Java, ejemplos (CLI y Terraform), troubleshooting, repaso y prompt de NotebookLM.
