# NotebookLM · AWS · 00 Fundamentos

**Fuentes a subir:** `README.md` y `repaso.md` de esta carpeta.

```
Crea un video largo y detallado en español latinoamericano, didáctico y cercano, solo sobre los fundamentos de AWS, para un ingeniero Java de microservicios que empieza. No compares con otras nubes.

Estructura obligatoria:
1. Qué es AWS con la analogía de la ciudad de servicios públicos y el terreno con escritura.
2. La jerarquía: Organizations, OU, cuentas, SCP, IAM Identity Center y por qué la cuenta es la frontera de aislamiento; cómo se lee un ARN.
3. Regiones, zonas de disponibilidad, ID de AZ, servicios regionales y globales; HA frente a DR; cómo elegir región.
4. Modelos de servicio con nombres de AWS y la responsabilidad compartida.
5. Cómo se habla con AWS: consola, CloudShell, CLI v2, SDK, IaC y API firmada; la cadena de proveedores de credenciales del SDK de Java; el hábito de ejecutar sts get-caller-identity.
6. Costos: modelo de pago, Savings Plans, los costos que sorprenden (NAT Gateway, transferencia, IPv4 pública, recursos olvidados, registros), presupuestos y etiquetas de asignación de costos.
7. Etiquetas y nombres; seguridad básica del día uno.
8. El caso de ModaLima, qué hacer y qué NO hacer, y el glosario.

Reglas: no omitas tablas ni comandos; define cada término la primera vez; usa ejemplos de ModaLima y Café Andino; cierra con 5 puntos de resumen y 3 preguntas de repaso.
```
